# 🎂 Kalpana's Cakes & Bakes

A modern and responsive bakery website built to showcase handcrafted cakes, pastries, and baked treats. The website is designed with performance, SEO, and user experience in mind, making it easy for customers to browse products and connect with the bakery.

## ✨ Features
- Responsive Design
- Modern UI/UX
- Cake Categories
- Product Gallery
- Contact & Inquiry Section
- SEO Optimized
- Fast Loading Performance
- Mobile Friendly

## 🛠️ Tech Stack
- Next.js
- React.js
- Tailwind CSS
- TypeScript
- Vercel
